# Temperature Converter

## Project Overview

This is a simple temperature converter web app that converts values between Celsius, Fahrenheit, and Kelvin. The app includes input validation and displays all three temperature scales after conversion.

## Files Included

- `index.html` - Application markup and form structure
- `style.css` - Styling for layout, form controls, and responsive visuals
- `script.js` - JavaScript logic for temperature conversion and validation

## Features

- Allows users to enter a numeric temperature value
- Lets users choose the input unit: Celsius, Fahrenheit, or Kelvin
- Converts the input value to all three temperature scales
- Shows real-time conversion results in a styled result panel
- Validates input and displays an error message when the value is invalid

## How to Use

1. Open `index.html` in a web browser.
2. Enter a temperature value in the input field.
3. Select the unit of the entered value (°C, °F, or K).
4. Click the "Convert" button.
5. Review the converted results for Celsius, Fahrenheit, and Kelvin.

## Notes

- The app prevents invalid values below absolute zero for the selected temperature scale.
- The interface is designed as a static front-end application and does not require a backend.
